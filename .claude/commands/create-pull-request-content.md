---
description: ブランチの変更を分析してプルリクテンプレートを埋めたマークダウンを生成
---

現在の作業ブランチについて、以下の手順でプルリクエストの内容を作成してください：

1. `git log main..HEAD --oneline` でコミット履歴を確認
2. `git diff main...HEAD` で全ての変更内容を確認
3. `git status` で現在の状態を確認

上記の情報を元に、以下のプルリクテンプレートを埋めてマークダウン形式で回答してください（そのままGitHubに貼り付けられる形式で）：

```
## 概要
<!-- この実装の概要や目的を記載してください -->

## 実装したこと
<!-- どのような変更を加えたのか具体的に記載してください -->

## 実装しなかったこと
<!-- 実装を見送った項目とその理由を記載してください -->

## UI
<!-- UIに変更があれば記載してください -->

## その他
<!-- その他補足があれば記載してください -->
```

注意事項：
- コミットメッセージとdiffの内容から具体的な変更を抽出して記載すること
- 各セクションは箇条書きで簡潔に書くこと
- UIの変更がない場合は「なし」と記載すること
- 実装しなかったことが特になければ「特になし」と記載すること
- マークダウンのコードブロックなどは使わず、そのまま貼り付けられる形式で出力すること
