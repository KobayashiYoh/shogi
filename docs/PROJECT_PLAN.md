# 将棋アプリ MVP 要件定義

## 📝 プロジェクト概要
React を使用して、ブラウザ上で動作する将棋アプリを MVP（Minimum Viable Product）として開発する。  
1 つの Web ブラウザ上で 2 人が交互に操作する、ローカル対戦用のシンプルな将棋アプリを目指す。

## ⏱ 開発目標
- Claude Code + GitHub Copilot を活用し、**約 2 時間で MVP を完成させる**
- まずは最低限遊べる機能に絞り、後からオンライン対応やAI対戦などを追加できる構成にする

---

## 🧱 技術スタック
- **フロントエンド**: React (TypeScript)
- **開発環境**: Vite
- **静的チェック**: ESLint + Prettier（CI による自動チェック）
- **状態管理**: React Hooks（useState / useEffect）

---

## 🧠 機能要件（MVP）
### 1. 盤面の表示
- 9×9 の将棋盤を表示
- 各マスに駒を配置（初期配置は通常の将棋の初期状態）
- 駒の種類・陣営を視覚的に区別できること

### 2. 駒の移動
- クリックした駒を選択し、移動可能なマスをクリックして移動
- 移動のルールは簡易的でよい（成りなどは MVP では考慮しない）
- 相手の駒を取ることができる（持ち駒にはせず単に除去）

### 3. 手番の管理
- 先手・後手のターンを交互に管理
- 現在どちらの番かを UI で表示

### 4. 勝敗判定
- 王将が取られた時点でゲーム終了
- 勝者を表示する簡単なモーダル or アラートを表示

---

## 🧪 非機能要件
- ESLint + Prettier による静的コードチェック
- ブラウザのリロードで盤面が初期化される仕様でOK（永続化はしない）

---

## 🚀 開発ステップ
1. **プロジェクト作成**
   - Vite で TypeScript プロジェクトを作成
   - ESLint / Prettier / CI 設定を導入

2. **盤面描画**
   - 9×9 の盤面コンポーネントを作成
   - 初期配置データ構造を定義

3. **駒移動ロジック**
   - 駒の選択と移動先クリックの処理を実装
   - 最低限の移動制限を加える（例：歩は前進1マスなど）

4. **手番管理**
   - 現在のプレイヤーを state で管理し、ターンごとに切り替える

5. **勝敗判定**
   - 王将が取られた時点でゲームを終了
   - 勝者をアラートまたはモーダルで表示

6. **最終調整**
   - 簡単なデザイン調整
   - ESLint / Prettier の修正

---

## 🌟 追加機能候補（MVP以降）
- 成り処理
- 持ち駒と打ち駒
- 棋譜の記録・再生
- オンライン対戦機能（WebSocket）
- AI 対戦（将棋ライブラリの利用）
